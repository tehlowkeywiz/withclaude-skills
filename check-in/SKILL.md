# Check in

Get up to speed on this project before doing any work, then tell me where it stands.

1. Read these from the project folder, if they exist:
   - `CLAUDE.md`: how this project works.
   - `handoffs/INDEX.md`, then the newest file in `handoffs/`: what happened last time.
   - If there is no `handoffs/` folder yet, read `HANDOFF.md` instead.
   - `PLAN.md` and `TASKS.md`: the goal and the tasks left.
2. Check for unsaved work: are there changes since the last save point, and is the last save point backed up to GitHub?
3. Tell me, in plain words and in a few lines:
   - What this project does.
   - What we did last time.
   - What's next: the first task, then one or two after it.
   - Any open question from last time I still have to answer.
   - Any work not saved or not backed up.
4. Don't change anything. Wait for me to say what we do next.

If there is no handoff at all, say so, tell me what you can see from the files, and remind me to run check-out at the end of this session so the next check-in has one.

Answer in the language I write in.
